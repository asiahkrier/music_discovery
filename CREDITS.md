# Credits

Spotify supplies artist metadata, remote artwork, catalog search and official embedded playback. Artwork links lead to Spotify. Ripple does not host the music; playback availability is controlled by Spotify. Missing artwork uses initials or the Ripple logo where appropriate.

Last.fm supplies biography summaries, similar-artist information, tags, listener counts and all-time song rankings. The interface includes source links. See [biographies](docs/biographies.md) and [recommendations](docs/recommendations.md).

The formerly bundled Radiohead demonstration photograph is no longer shipped. Historical sprint documents retain their original evidence.
